# Elite Chess

**Play:** https://dizneypls-dot.github.io/greenwood-chess/
On iPhone open it in Safari → Share → Add to Home Screen; on Android use Chrome → Install app, or get the APK below.

- **Android app:** [EliteChess.apk](https://dizneypls-dot.github.io/greenwood-chess/EliteChess.apk)
- **Single-file copy** that works offline from a phone's files: [Elite-Chess.html](https://dizneypls-dot.github.io/greenwood-chess/Elite-Chess.html)

27 characters to play (Stockfish 17.1 at calibrated ratings), puzzles, lessons, online play, FIDE rankings, legends of chess,
seasonal themes with animated character pieces, and recorded board sounds. Credits are in the app under Profile → About.
